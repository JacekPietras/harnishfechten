# DDHF Tournament Framework — judge procedure reference

> **Status:** General HEMA tournament framework, not a Harnischfechten ruleset. It does not define discipline-specific scoring; it is relevant only as a reference for tournament procedure, officials, and judge responsibilities.

## Source

- Deutscher Dachverband für Historisches Fechten (DDHF), *DDHF Rule Framework*, English PDF, translated from version 6.0 (18 February 2025).
- [Original PDF](https://ddhf.de/wp-content/uploads/2025/02/DDHF-Rahmenregelwerk_v6.0-EN.pdf.pdf)

## Scope

The framework sets general requirements for tournaments and says hit-scoring and advancement rules belong in a separate core rulebook used together with the framework. It is therefore useful for structure and procedure, but not as a source for Harnischfechten target or point rules.

## Officials and responsibilities

- Tournament management organizes, runs, and documents the tournament; it has final authority on rules questions and ensures each bout has at least one referee and one assistant.
- Referees lead bouts with commands and signals, decide hit validity and scoring, announce bout results, and may issue disciplinary cards or exclude a fencer.
- Assistants support documentation and, where needed, timekeeping.

## Possible use in the local judge guide

This framework can inform sections on judge authority, bout commands, score recording, rule interpretation, and the distinction between the bout referee and tournament management. The local guide will still need its own Harnischfechten-specific scoring rules.

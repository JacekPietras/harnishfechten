# Zasady projektu

- Pisz zwięźle. Podawaj tylko informacje potrzebne do wykonania zadania lub podjęcia decyzji.
- Pomijaj ogólne wprowadzenia, oczywiste wyjaśnienia i powtórzenia.
- Formułuj zasady i rekomendacje jako konkretne decyzje, które można osobno omówić lub zmienić.
- Gdy decyzja zależy od założeń, nazwij je krótko. Nie przedstawiaj przypuszczeń jako ustaleń.
- Przy zmianach w projekcie zachowuj istniejący zakres i styl; nie dodawaj treści ani złożoności bez potrzeby.
- Jeśli brakuje informacji, przyjmij najprostsze rozsądne założenie i wskaż je zwięźle.
